¡Hola! Bienvenidos a mi blog personal creado con **Hugo** y desplegado automáticamente en **GitHub Pages**.

## ¿De qué trata este espacio?
Este sitio web forma parte de las prácticas del módulo de **Implantación de Aplicaciones Web (IAW)** del ciclo formativo de ASIR. Aquí iré documentando los diferentes despliegues, pruebas y configuraciones de servidores y aplicaciones web.

### Tecnologías utilizadas:
* **Hugo:** Como generador de sitios estáticos rápido y flexible.
* **Git y GitHub:** Para el control de versiones y el alojamiento del código fuente.
* **GitHub Pages:** Como plataforma de hosting estático en la nube.
